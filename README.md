# Vitor Lior — Treinamento Personalizado

Landing page premium para personal training e consultoria fitness, construída com Next.js, React e TypeScript.

## Site público

[barretomen.github.io/vitor-lior-performance](https://barretomen.github.io/vitor-lior-performance/)

## Desenvolvimento local

```bash
npm ci
npm run dev
```

O deploy do GitHub Pages é executado automaticamente pelo workflow em `.github/workflows/pages.yml`.

> O formulário da versão no GitHub Pages prepara as respostas para envio pelo WhatsApp, pois o Pages não executa APIs de backend.
